# foresma_doc

foresma社の営業資料・マーケティング知見を、**マーケターがチャットだけで作成・更新**できるようにするためのリポジトリです。

## 使い方（マーケター向け）
- Cursorのチャットで「作りたい資料」を伝えるだけでOK。
- コードやコマンドは不要。作成物はNotionに貼れる形で整形されます。

## ディレクトリ構成
- `docs/`: 社内ドキュメント（Markdown中心）
- `slides/`: スライド原稿（Markdown中心）

## 運用ルール
- Cursorのプロジェクトルールは `.cursor/rules/foresma_marketer.md` を参照します。
