# エージェント紹介ページ 設計資料

## メタ情報
- **タイトル**: 着座率向上のためのエージェント紹介ページ
- **目的**: 予約後の面談着座率を向上させる
- **対象読者**: CS・IS担当者、マーケティング担当
- **想定シーン**: LINE送客後、面談予約完了時
- **タグ**: #着座率改善 #LP #エージェント紹介
- **最終更新**: 2026-01-23

---

## 📋 課題と解決策

### 現状の課題
- **予約したけど面談に来ない（着座しない）ケースが多発**
- 予約時点での動機付けが弱い
- 面談の価値が不明確

### 解決アプローチ
1. **モザイク表示による期待感の醸成**
   - 3社をモザイクで隠すことで「知りたい」という心理を刺激
   - 「面談でのみ公開」という限定性を強調

2. **パーソナライズ感の強化**
   - 求職者名を明記した専用ページ
   - 希望条件の確認セクションで「自分のために用意された」感を演出

3. **具体的なベネフィット提示**
   - マッチ度の数値化（95%以上）
   - 面談で得られる4つの価値を明示
   - 利用者の声で社会的証明

4. **緊急性の創出**
   - 48時間限定のカウントダウン
   - 求人状況の変動を示唆

## 🎯 ページ構成と設計意図

### 1. ヘッダーセクション
```
【要素】
- 求職者名（泉舞衣子さん専用）
- キャッチコピー「ピッタリのエージェント3社が見つかりました」
- 担当者の挨拶（黒崎）
- 希望条件の確認ボックス

【狙い】
- パーソナライズ感で「自分専用」と認識させる
- 希望条件の再確認で「間違いない」という安心感
```

### 2. メインメッセージ
```
【要素】
- 「泉舞衣子さんだけの特別な3社」
- マッチ度95%以上の強調
- 「面談でのみお伝え」の限定性

【狙い】
- 特別感と希少性で価値を高める
- 面談に参加しないと損という心理
```

### 3. エージェントカード（3枚）
```
【要素】
- モザイクがかかったロゴエリア

- 「面談で公開」の明示

【狙い】
- モザイクで「見たい」欲求を刺激
- 具体的な情報で信頼性を担保
- 3社それぞれの差別化でバラエティ感
```

### 4. カウントダウンタイマー
```
【要素】
- 48時間限定の表示
- 黄色の注意喚起カラー

【狙い】
- 緊急性で即行動を促す
- 「今予約しないと損」という心理
```

### 5. CTA（行動喚起）セクション
```
【要素】
- 面談で得られる4つの価値
  1. 3社の詳細情報
  2. 専用の転職戦略
  3. 非公開求人の紹介
  4. 書類通過率UP支援
- 利用者の声（社会的証明）
- 緊急性メッセージ
- 大きな予約ボタン

【狙い】
- 面談の具体的価値を明確化
- 複数のベネフィットで納得感
- 社会的証明で安心感
- 最後の一押しで予約完了へ
```

## 💡 着座率向上のための工夫

### 心理トリガー

1. **希少性（Scarcity）**
   - 「48時間限定」
   - 「求人状況は日々変動」
   - 「面談でのみ公開」

2. **パーソナライゼーション**
   - 求職者名の明記
   - 希望条件の具体的表示
   - 「あなた専用」の強調

3. **社会的証明（Social Proof）**
   - 利用者の声
   - 実績数値（年収アップ率、定着率など）

4. **権威性（Authority）**
   - 「逆転転職コンサルタント」の肩書
   - 担当者名の明示（黒崎）

5. **好奇心（Curiosity）**
   - モザイクによる隠蔽
   - 「面談で公開」の限定情報

6. **具体性（Specificity）**
   - マッチ度の数値化（98%, 96%, 95%）
   - 4つの明確なベネフィット

## 📊 効果測定指標（KPI）

### 測定すべき指標

1. **予約完了率**
   - ページ訪問 → 予約ボタンクリック率
   - 目標：30%以上

2. **着座率（最重要）**
   - 予約完了 → 実際の面談参加率
   - 目標：従来比+20%

3. **ページ滞在時間**
   - 目標：平均2分以上
   - （しっかり読んでいる証拠）

4. **スクロール深度**
   - 最下部のCTAまで到達した割合
   - 目標：70%以上

5. **離脱ポイント分析**
   - どのセクションで離脱が多いか
