## 1. 要約

「出会えるエージェント」のサービス説明動画（30秒）を制作する。
**女性ナビゲーター（立体感のあるイラスト）が話しながら**、イラストのアニメーションで次の2つのメリットを伝える。

1. エージェントごとに紹介できる求人はバラバラ → **複数社を比べると、より良い求人に出会える**
2. **3社を比べると、自分の市場価値が正確にわかる**

利用の流れは「**LINEで登録 → 15分の面談 → ピッタリの3社をご紹介**」。最後はLINEの友だち追加へ誘導する。

## 4. 訴求内容

### 伝えること（必須）
- エージェントごとに紹介できる求人はバラバラ → 複数を比べるほど良い求人に出会える
- 3社を比べると市場価値が正確にわかる
- 利用の流れ：LINEで登録 → **15分の面談**で希望をヒアリング → ピッタリの**3社**をご紹介
- 高評価のエージェントだけ（ハズレなし）
- 完全無料
- CTA：LINEで友だち追加

### 使わない表現（NG）
- 「LINEで完結」「LINEだけでOK」など、面談がないように見える表現

## 7. 音声仕様

### ナレーション
| 項目 | 仕様 |
|------|------|
| 声 | 人の女性に近い、アナウンサー調の聞きやすい声 |
| 使用音声 | VOICEVOX「九州そら（ノーマル）」 |
| 調整 | 話す速さ1.5倍、抑揚1.2、読点の間は0.2秒まで（30秒に収めるため） |
| 合計の長さ | 約24秒（8セリフ） |
| 利用条件 | 商用利用可。**「VOICEVOX:九州そら」のクレジット表記が必須**（動画の最後に表記済み） |
| 代わりの候補 | 冥鳴ひまり／WhiteCUL／四国めたん（いずれも商用利用可・クレジット表記が必要） |
| 使わない音声 | No.7（アナウンス）：企業の商用利用には事前確認が必要なため |

### BGM
| 項目 | 仕様 |
|------|------|
| 雰囲気 | テンションが上がる、ドーパミンが出るような明るい曲 |
| ジャンル・テンポ | ダンスポップ／EDM系、128BPM |
| コード進行 | 王道進行（F→G→Em→Am） |
| 構成 | 冒頭①：盛り上げパート（こもった音が徐々に開く、スネアの連打が速くなる、上昇音）→ ②の頭でサビに入る（衝撃音＋シンバル）→ 4つ打ちのキック、クラップ、オープンハイハット、キックに合わせてうねるシンセのコード、ベース → ③からリードの主旋律 → ⑤でリードを1オクターブ上に重ねてピーク → 最後に大きなコードで締める |
| 声とのバランス | 話している間はBGMを自動で約28%に下げ、声がBGMより約9dB大きく聞こえるようにする |
| 権利 | 今回の動画用に作ったオリジナル曲のため、著作権上の制約なし |

### 効果音
- シーン切り替え：シュッという風切り音
- カード・吹き出し・ステップ・バッジの登場：ポップ音
- 好条件の求人が光る場面・市場価値が決まる場面：チャイム
- スポットライトが当たる場面：低い風切り音
