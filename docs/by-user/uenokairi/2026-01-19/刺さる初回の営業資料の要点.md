# 要約
初回の営業資料は「提案書」とは別物で、どの顧客にも使い回せる鉄板資料であるべき。表紙は「内容のキーメッセージ」を明確にし、個社の課題指摘ではなく市場トレンドを軸に語る。ストーリーはトレンド→機会/緊急性→成功事例の流れで進め、製品説明は必要最小限に留める。ロゴは意図的に並べて質問を誘発し、事例ストーリーで理解と信頼を高める。

# 重要な前提
- 提案書≠初回の営業資料
- 初回資料は個別最適よりも汎用性を重視
- 会社紹介・製品紹介は主役ではなく、信頼を損なわない程度に最小限

# 表紙とキーメッセージ
- 表紙は「○○ご紹介」ではなく、内容のキーメッセージを置く
- キーメッセージは顧客課題の指摘ではなく、市場の大きなトレンドから始める
- トレンドを置くことで、聞き手が受け入れやすくなる

# ストーリー構成（基本の流れ）
1. 市場トレンドを提示する
2. トレンドが生む機会・緊急性を語る
3. 変革に成功した顧客事例を語る

# ロゴの使い方
- ロゴは無作為に並べず、意図を持って配置する
- 業種別や企業規模別のグルーピングで説得力を高める
- ロゴ掲載は質問の入口。質問が来たら事例ストーリーで深掘りする

# 事例の語り方
- 企業の簡単な説明
- 導入に至った背景
- 具体的な取り組み

# 製品説明の位置づけ
- 製品説明は少なくてよい
- ストーリーの流れが整っていない状態で製品説明から入ると刺さらない

# 聞き手の想定について
- 聞き手の想定は資料以前のターゲティングで済ませる
- ターゲティングされた層には資料が刺さる設計にする

# 注意点
- 初回資料は「顧客を責める構図」にしない
- トレンド起点で、聞き手が前向きに受け止められる構成にする

# 次にやること
- 既存の初回資料の表紙を「市場トレンド起点」に書き換える
- ロゴ配置を「業種別/規模別」に再設計する
- 代表的な顧客事例をストーリー形式で用意する
