# 概要
noteの新機能として、記事内に「友だち追加で読む」ボタンを設置し、読者をLINE公式アカウントへ誘導できるようになった。これまで法人向け限定だった機能が全クリエイターに開放され、無料トライアルも実施中。

# できること
- 記事内の任意の位置に「友だち追加で読む」ボタンを設置
- ボタン経由でLINE公式アカウントへ遷移し、そのまま友だち追加
- 追加後に記事の続きを読む案内を送付可能
- 高い関心を持つ読者と継続的につながれる

# 期待できる効果
- 記事で興味を持った読者を、公式アカウントへ確実に誘導
- 読者との接点を継続し、告知・案内の到達率を高める
- 予約や販売など、外部導線への誘導に活用できる

# 想定ユーザーと活用例
- 店舗・サロン運営: 予約案内、クーポン配布、新メニュー告知
- ものづくり・創作: 新作先行公開、オーダー受付、イベント案内
- 教室・講座運営: 体験レッスン申込、カリキュラム詳細の限定公開

# 料金とキャンペーン
- 月払い: 17,380円（税込）
- 年払い: 187,704円（税込、月換算15,642円）
- 申込期間: 1月15日 10:00〜1月31日 23:59
- 無料期間: 申込完了日〜2月28日 23:59
- 無料期間終了後: 3月1日から自動的に有料プランへ移行
- 解約期限: 2月28日 23:59までに解約で料金発生なし

# 導入条件
- LINE公式アカウントとの連携設定が必須
