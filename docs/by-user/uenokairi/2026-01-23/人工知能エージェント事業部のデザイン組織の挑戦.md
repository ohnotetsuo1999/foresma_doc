# 要約
LayerXのAi Workforce事業部は、人工知能エージェントを基盤としたプロダクトを開発する中で、プロダクトデザインとコミュニケーションデザインの二領域で組織を構成している。汎用プラットフォームの設計と、個別顧客の課題解決を両立する二層構造が特徴で、体験の汎用性と個別最適のバランスが主要テーマ。AIという無機質に見えがちな技術を、誰にでも伝わる言葉と表現で翻訳することが重要な役割となっている。組織は立ち上げ期から急拡大期に移行しており、採用と共通言語づくりが今後の重点課題。

# 根拠
## デザイン組織の構造
- **二領域の分担**: プロダクトデザインとコミュニケーションデザインで役割を分け、体験設計と社会への価値翻訳を両立
- **二層構造の設計**: 汎用プラットフォームの設計と個別顧客（N1）支援を並行し、汎用性と個別最適の緊張関係を常に調整

## プロダクト体験の特徴
- **対話型体験が中心**: 既存のSaaS型UIとは異なり、ボタンやフィードバック表示が減る中で安心感や進行状況の可視化を工夫
- **汎用性の担保**: 個別課題の解決に偏りすぎるとスケーラビリティが下がるため、抽象化して再利用可能な価値に整理

## コミュニケーションデザインの役割
- **AI価値の翻訳**: 技術が難しいほど、専門用語を避けて理解できる言葉に落とし込む
- **人間的領域への接続**: 組織づくりやチームビルディングなど、ウェットな領域にAIの価値を橋渡し

# 事例
## 伝わる言葉への変換
- AIに詳しくない視点に立ち、用語や図表を整理
- 社内外の壁打ちを活用して理解しやすさを検証

## プロダクト体験の検証
- SaaS的なUIとAIエージェントらしいUIを並行で設計し、体験の汎用性と使いやすさを比較検討

# これからの挑戦
- **立ち上げ期と急拡大期の同居**: 体制整備と採用強化を同時に進める必要
- **共通言語づくり**: 事業部とプロダクトの用語・価値を定義し、意思決定の質を上げる
- **ユーザー理解の深化**: 現場観察と改善サイクルで実利用に根ざした体験に磨く

# 次にやること
- AIエージェント体験に必要な安心感の設計要素を整理する
- 汎用性と個別最適の判断基準を自社基準として明文化する
- 専門用語を平易化した説明テンプレートを作成する
